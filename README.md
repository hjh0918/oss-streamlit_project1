#  MoneyLog - 개인 재무 관리 앱

> Streamlit 기반 개인 재무 관리 웹 애플리케이션

---

##  프로젝트 소개

MoneyLog는 가계부 작성, 소비 성향 분석, 소비습관 설문을 하나의 앱에서 경험할 수 있는 개인 재무 관리 앱입니다.
가계부 데이터를 바탕으로 나의 실제 소비 패턴을 분석하고, 설문을 통한 소비습관 진단 결과와 비교해볼 수 있습니다.

## 주요 기능

-  **로그인 / 회원가입** — 아이디/비밀번호 기반 로그인, 쿠키를 활용한 로그인 상태 유지
-  **가계부** — 계정과목별 지출 입력/삭제, 월별 지출 분석 차트
-  **소비성향 분석** — 가계부 데이터 기반 50/30/20 법칙 적용 자동 분석
-  **소비습관 설문** — 20문항 설문을 통한 소비 유형 진단
-  **결과 비교** — 설문 결과 vs 가계부 데이터 기반 결과 비교
-  **경제 퀴즈** — 난이도별 경제 상식 퀴즈 (하/중/상, 총 300문항)
